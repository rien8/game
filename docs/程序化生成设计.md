# 程序化生成设计（PCG）

> 目标：每次游玩的世界、地图、怪物、怪物外观都不一样，且同一 seed 可完全重现。

---

## 一、核心原则：从"随机"到"可控随机" ⭐

这是 PCG 成败的分水岭。

1. **用伪随机 + seed，不用真随机** —— 同一个 seed 永远生成同一个世界，可**重现、可分享、可调试**（报 bug 时给 seed 就能复现）。
2. **分层继承 seed** —— `世界种子 → 地图种子 → 物种种子 → 个体种子`，每层往下派生，改一个 seed 就能改整个世界。
3. **规则约束 + 随机点缀** —— 不是纯随机乱生成，而是"规则保证合理（生物要能存活、地图要连通），随机提供变化"。
4. **生成参数暴露给玩家** —— 让玩家输入自定义 seed（"分享你的世界"），是很好的传播点。

---

## 二、随机世界

世界 = **一个种子 (seed) + 生成规则链**：

```
世界种子
  ├── 地形（噪声）
  ├── 气候带
  ├── 资源分布
  ├── 初始物种池（随机抽出 N 个物种作为开局）
  └── 事件节奏（灾变、资源枯竭的时间点）
```

- 所有随机都从同一个 seed 派生，形成"世界唯一且可重现"的链。
- 存档只需存 seed + 关键参数，世界能完整重建。

---

## 三、随机地图

核心是**噪声 + 种子**：

| 技术 | 用途 |
|------|------|
| **Perlin / Simplex 噪声** | 地形高度图、温度、湿度 |
| **分形噪声 (fBm)** | 山脉、起伏的层次感 |
| **Voronoi 图** | 划分区域 / 生态圈 / 领地 |
| **元胞自动机** | 洞穴、不规则结构 |
| **Diamond-Square** | 山地地形 |

叠加**多层噪声**（海拔 + 温度 + 湿度）→ 自动推导**生物群系**（草原/森林/沙漠/沼泽/冰原）。

---

## 四、随机怪物（属性 + 行为 + 名称）

| 维度 | 生成方式 |
|------|---------|
| **属性** | 基因映射：生命/攻击/速度/抗性，基因位决定数值区间 |
| **行为** | 基因决定 AI 倾向：草食/肉食/迁徙/领地/群居 |
| **名称** | 音节组合程序生成（如"鳞·噬渊者"），基因决定名字 |

---

## 五、随机怪物外观（2D 方案）

最主流、效果最好的是**部件拼接法**：

```
基因型（bit 数组）
  ├── 身体部件：头 / 躯干 / 前肢 / 后肢 / 尾巴 / 角 / 翅膀 …（每类 5-20 套变体）
  ├── 颜色：调色板（主色/次色/花纹），由基因映射 HSL 偏移
  ├── 比例：各部件大小、位置、数量（几对腿、几根角）
  └── 纹理：花纹（条纹/斑点/渐变）由噪声 + 基因决定
```

- **同一基因 → 同一外观**（可重现），基因变异 → 新外观。
- 参考：**Spore**（部件组合）、**No Man's Sky**（体素+部件）。
- 本游戏中，生物的"基因"本就该驱动外观——**外观 = 基因的表现型**，演化和外观天然绑定。

---

## 六、与"世界自动演化"的合流

演化引擎负责"生物怎么变"，PCG 负责"世界/地图/外观怎么生成"，两者都用**基因 + seed** 贯穿，架构统一：

```
基因型（seed 派生）
  ├── PCG：决定初始世界 / 地图 / 物种 / 个体外观
  └── 演化：变异 → 自然选择 → 精英怪 / Boss 诞生
```

- 精英怪 / Boss 的"独立外观"就是其基因型的表现，无需单独美术。
- 变异直接体现在外观变化上，玩家能"看见演化"。

---

## 七、技术选型

| 需求 | 推荐 |
|------|------|
| 噪声库 | **FastNoiseLite**（单头文件，Perlin/Simplex/Voronoi 全有） |
| 随机数 | C++23 `<random>` 的 `std::mt19937_64` 或 **PCG32** |
| 外观 | 部件拼接 + SDL3 纹理（`SDL_CreateTexture` 动态拼图） |
| 数据存储 | seed + 生成参数（存档只需存 seed，世界能完整重建） |

---

## 八、原型路线图（可运行）

1. **随机地图原型** —— 用 FastNoiseLite 生成地形高度图 + 生物群系，渲染成 tile 地图。
2. **随机怪物原型** —— 基因型 → 部件拼接 → 渲染出一个怪物 sprite，变异出新外观。
3. **seed 贯通** —— 同一 seed 重现同一世界；输入不同 seed 得到不同世界。
4. **接入演化引擎** —— 生物用基因繁殖/变异，精英怪/Boss 从变异中涌现。
