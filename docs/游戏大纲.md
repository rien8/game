# 游戏大纲：模拟经营 × 世界演化

暂定名 **《世界意志》(World Will)**

## 一、核心概念

玩家扮演一位**世界意志 / 守望者**，经营一个**会自动演化**的世界。与传统经营游戏不同，玩家**不逐格建造**，世界有自身的生态逻辑——生物会迁徙、繁衍、变异、竞争、进化，环境会变迁。玩家是"引导者"而非"上帝之手"，用**有限的干预手段**和**一锤定音的世界祝福**去塑造演化方向。

**一句话卖点：** 你不建造世界，你选择世界会诞生什么样的神明与灾厄。

---

## 二、核心循环（Core Loop）

```
观察（世界自动演化）
   ↓
干预（有限的经营手段 + 资源分配）
   ↓
涌现（精英怪 / Boss 诞生，改变世界规则）
   ↓
抉择（世界祝福——每阶段仅一次）
   ↓
结算晋升（进入下一纪元，演化规则升级）
```

---

## 三、世界自动演化系统

这是整个游戏的"引擎"，**无脚本、靠涌现**：

| 子系统 | 演化逻辑 |
|--------|---------|
| **生物** | 携带基因（外观/属性/行为），变异 + 自然选择，种群消长、迁徙、食物链 |
| **环境** | 地形、气候带、资源分布随时间和生物活动而变化 |
| **生态事件** | 灾变、物种入侵、资源枯竭、共生关系等随机但可追溯的事件 |
| **世界能量** | 演化过程积累"世界能量"，是精英怪/Boss诞生的燃料 |

关键设计：世界演化是**持续、可见、可被玩家观察**的，玩家能看懂"为什么这只怪变强了"。

---

## 四、精英怪与 Boss 诞生

**精英怪（Elite）：**
- 演化中，个体因基因突变 / 环境压力 / 资源富集突破阈值，成为精英怪
- 属性远超普通个体，是种群中的"变异王者"，有独立外观和名字
- 诞生条件可追溯：玩家能回看它的"成长史"

**Boss 诞生：**
- 精英怪持续成长、吞噬、吸收世界能量，达到临界点后**蜕变**为 Boss
- Boss 诞生会**改变世界规则**：区域气候巨变、物种灭绝风险、生态位洗牌
- Boss 有多个走向：**灾厄**（威胁世界）、**守护者**（庇护生态）、**灾厄+守护的混沌体**

---

## 五、世界祝福系统（核心特色）⭐

- 玩家可以**选中任意一个精英怪**，赐予"世界祝福"
- 祝福让它获得特殊进化方向 / 能力 / 命运，而非简单数值加成
- **每阶段（纪元）仅可使用一次** → 是阶段内最重大的战略决策
- 祝福的连锁反应塑造后续演化：

| 祝福类型 | 效果示例 |
|---------|---------|
| 祝福·繁荣 | 精英怪成为"守护者"，庇护整个物种，生态稳定 |
| 祝福·灾厄 | 精英怪成为"天灾"，主动清扫竞争物种，快速催生Boss |
| 祝福·蜕变 | 精英怪直接走向 Boss 路线，但结果不可控 |
| 祝福·诅咒 | 反向祝福：压制其成长，或制造"可控的灾厄" |

**决策张力：** 一次祝福可能救活濒危物种，也可能亲手培养出毁灭世界的 Boss。

---

## 六、经营 / 管理要素

| 资源 | 获取方式 | 用途 |
|------|---------|------|
| **信仰** | 生物繁荣、生态稳定时产出 | 主要货币，购买干预手段 |
| **世界能量** | 演化 + 精英怪/Boss 事件 | 高级干预、触发祝福的资格 |
| **生命精华** | 生物死亡/灭绝时掉落 | 复活、催生特定物种 |

玩家有限的**主动手段**（均消耗资源）：
- 地形微调（小范围改变地貌）
- 气候干预（短期改变区域气候）
- 生态介入（引入/保护/放逐物种）

---

## 七、阶段 / 纪元结构

- 每个**纪元**是一次完整的演化弧线，有明确的**开局环境**与**终局结算**
- 世界祝福每纪元仅一次，是纪元的"王炸"级抉择
- 纪元结束结算：存活物种数、世界能量、Boss 结局 → 影响下一纪元的世界起点
- 随纪元推进，**演化规则解锁升级**（新基因、新物种谱系、更复杂的生态链）

---

## 八、可选玩法扩展

1. **传承系统**：被祝福的精英怪/Boss 在纪元间以"传说/遗骸/血脉"形式残留
2. **图鉴与编年史**：世界自动生成历史（谁诞生、谁灭绝、谁被祝福）
3. **多世界并行**：同时经营多个世界，对比不同祝福路线的演化结果

---

## 九、技术实现映射（对应 gamev2 项目）

- **渲染**：SDL3 / SFML（已配置）
- **生态模拟**：ECS 架构 + 实体池（契合 CLAUDE.md 的性能约束）
- **基因/演化**：位运算基因型 + 变异算子
- **世界能量/事件**：事件队列 + 权重系统
- **涌现逻辑**：规则驱动，避免硬编码脚本
